ПРОЕКТ №3 — «Словарь / Flashcards»

Что реализовано:
- добавление слова, перевода, примера, языка и темы;
- локальное хранение слов в SQLite;
- список слов и удаление;
- карточки «слово → перевод»;
- кнопки «Знаю / Не знаю» и интервалы повторения 1, 3, 7, 14 дней (далее до 30);
- тест с вариантами ответа;
- статистика количества слов, выученных слов и процента;
- переключение светлой/тёмной темы.

Как открыть:
1. Распакуйте ZIP.
2. Откройте Android Studio (или совместимую IDE) → Open.
3. Выберите папку FlashcardsProject, а не отдельный файл.
4. Дождитесь Gradle Sync. Нужен Android SDK 35 и JDK 17.
5. Запустите на эмуляторе или Android-устройстве.

Примечание:
Это учебная рабочая базовая версия. Уведомления через AlarmManager/WorkManager не добавлены;
повторение рассчитывается и показывается внутри приложения. Если по требованиям преподавателя
обязательны системные уведомления, их нужно добавить отдельным этапом.
